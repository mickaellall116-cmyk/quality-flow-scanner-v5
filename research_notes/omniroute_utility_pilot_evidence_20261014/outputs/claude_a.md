Question 1: Does sorting large-cap U.S. stocks on their prior 4-hour return produce a top-minus-bottom quintile spread with a positive average return over the next 4 hours?
Null hypothesis: The mean next-4-hour return of the top-minus-bottom quintile spread is less than or equal to zero.
Data required: 4-hour OHLCV bars for the 214 large-cap index constituents named in the abstract, January 2015 to December 2024, sufficient to compute prior-4-hour returns, quintile assignments, and next-4-hour returns.

Question 2: Is the spread return concentrated in the first hour after portfolio formation rather than spread evenly across the following 4 hours?
Null hypothesis: The first hour contributes the same share of the next-4-hour spread return as each subsequent hour (no concentration in hour one).
Data required: The same constituent universe and sample period as Question 1, but with 1-hour (or finer) bars so the next-4-hour spread return can be decomposed by hour after formation.
