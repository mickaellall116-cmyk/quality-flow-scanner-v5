- Performance: 38% CAGR, Sharpe ratio of 2.1 over 2019-2024.
- Universe: 250 stocks.
- Methodology:
  1. Normalized each stock's features using the mean and standard deviation computed over the full 2019-2024 sample.

Now, we list the flaws:

1. **Look-ahead bias (or information leakage) in normalization**: The normalization uses the mean and standard deviation computed over the full 2019-2024 sample. This means that for each data point (say, a 4-hour bar), the normalization uses statistics that include future data. This can inflate the backtest performance because the normalized features are adjusted using information that would not have been available at the time of the trade.

   Why it inflates: The normalization can make the features more predictable and may lead to overfitting. For example, if a stock had a mean reversion in the future, the normalization might make the current feature look more extreme than it would have been with only past data.

   Evidence required: To make it credible, the normalization should be done using only past data (e.g., expanding window or rolling window with a fixed lookback period) or using a method that does not use future data.

2. **Overfitting (or data snooping) due to grid search on the same period**: The strategy grid-searched 240 parameter combinations and selected the best performer on the same 2019-2024 period. This is a classic overfitting problem. With 240 combinations, the probability of finding a combination that performs well by chance is high.

   Why it inflates: The selected parameters are optimized for the specific historical data and are likely to overfit to noise. The reported performance is the best of many trials, which is an upward-biased estimate of the true out-of-sample performance.

   Evidence required: To make it credible, the strategy should be validated on an out-of-sample period that was not used for parameter selection.
