## 6. Verdict computation (B2 economics-first — worked form)

For each test: estimate θ̂, one-sided 95% interval [L, U] (wider of the two bootstrap intervals; Holm-adjusted for the H-EXIT family), δ per checklist §4.

1. Floors or §3/§10 gates unmet, or a §9/deviation condition applies → **INCONCLUSIVE** (with UNDERPOWERED FOR PASS where §6 applies).
2. Else U < δ → **FAIL** (EXCLUDED).
3. Else θ̂ ≥ δ and L > 0 → **PASS** — grade **CONFIRMED AT δ** if L ≥ δ, else grade **ECONOMICS-FIRST**.
4. Else (θ̂ < δ with L > 0, or L ≤ 0 with U ≥ δ) → **INCONCLUSIVE** (POSITIVE, NOT CONFIRMED AT δ, or INDETERMINATE, as the interval dictates).

Edge rule (§11): Stage A alone supports no edge claim. "Edge supported" requires Stage B PASS on H-SYS-1 **and** Stage A not FAIL; a Stage A FAIL on H-SYS-1 is "edge rejected" — noting precondition §3.6: a floor-short H-SYS-1 returns INCONCLUSIVE, not FAIL, so on the expected counts Stage A's edge-rule contribution is its paired-leg verdicts and a not-FAIL system reading, exactly as pre-declared.

## 7. Stop / report protocol

**STOP immediately, preserve everything, touch nothing further** on any of: pin or hash mismatch (steps 0–1); discovery that the §9 outcome was logged differently than the audit found; any unplanned look at performance output before step 4 completes; script failure after data access; telemetry journal write failure; any pressure — from anyone, in any channel — to re-run, subset, or adjust mid-session.

On STOP: (1) freeze the session state exactly as it stands (logs, partial outputs, journal); (2) notify Mike the same day with the exact evidence (what failed, at which step, what had been accessed by then); (3) the window's consumption status is assessed honestly — if holdout outcomes were computed or viewed, the tier is consumed for this rule version even though the run aborted; (4) affected verdicts default to **INCONCLUSIVE** unless Mike + Muse declared the specific deviation immaterial **before** unblinding (§11) — a declaration made after outputs were seen is not possible by definition; (5) any resumption is a new decision by Mike on the logged evidence, never an in-session retry.
